# Soft Computing Practicals

This repository contains practical implementations and assignments for Soft Computing.

## Module 2: Artificial Neural Networks

This module focuses on the fundamental concepts of Artificial Neural Networks (ANN), ranging from building a basic neuron from scratch to designing and training a complete classification system using Keras and TensorFlow.

### Tasks Implemented:
1. **[Task 1](Module_2/task_1.py)**: Understand and implement the basic working of an artificial neuron using Python.
2. **[Task 2](Module_2/task_2.py)**: Implement the weighted sum of inputs and bias used in an artificial neuron.
3. **[Task 3](Module_2/task_3.py)**: Implement and visualize Sigmoid, Tanh, and ReLU activation functions using Python and Matplotlib.
4. **[Task 4](Module_2/task_4.py)**: Create a simple single-layer neural network using Python.
5. **[Task 5](Module_2/task_5.py)**: Create a Multilayer Perceptron (MLP) with input, hidden, and output layers using Keras/TensorFlow.
6. **[Task 6](Module_2/task_6.py)**: Apply Gradient Descent for updating the weights of a simple neural network during training.
7. **[Task 7](Module_2/task_7.py)**: Understand and implement the basic concept of Backpropagation for training a neural network from scratch (solving the XOR problem).
8. **[Task 8](Module_2/task_8.py)**: Train a simple neural network model on a dataset using Keras/TensorFlow.
9. **[Task 9](Module_2/task_9.py)**: Evaluate the performance of a trained neural network using suitable evaluation metrics (Accuracy, Precision, Recall, F1 Score).
10. **[Task 10](Module_2/task_10.py)**: Design, train, and evaluate a complete Artificial Neural Network-based classification system.

## Prerequisites

To run these scripts, you will need the following Python libraries installed:
- `numpy`
- `matplotlib`
- `scikit-learn`
- `tensorflow`

You can install the dependencies using pip:
```bash
pip install numpy matplotlib scikit-learn tensorflow
```

## How to Run

Navigate to the `Module_2` directory and run any of the task files using Python. For example:
```bash
cd Module_2
python task_10.py
```
